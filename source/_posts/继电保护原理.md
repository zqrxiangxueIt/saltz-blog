# 第1章 绪论

## 1.1 电力系统的运行状态

### 1.1.1 三种运行状态

电力系统运行状态根据对等式和不等式约束条件的满足情况分为三类：

#### 等式约束条件（由电能性质决定）
系统发出的有功/无功功率在任一时刻应与负荷功率（含传输损耗）相等：

$$\sum P_{Gi} - \sum P_{Dj} - \sum \Delta P_S = 0$$
$$\sum Q_{Gi} - \sum Q_{Dj} - \sum \Delta Q_S = 0$$

#### 不等式约束条件（供电质量和设备安全）
$$U_{i\min} \leq U_i \leq U_{i\max}$$（电压偏差 ±5%\~±10%）
$$f_{\min} \leq f \leq f_{\max}$$（频率偏差 ±0.2%\~±1%）
$$S_k \leq S_{k\max}$$（功率潮流上限）
$$I_{ij} \leq I_{ij\max}$$（线路电流上限）

#### 三种状态

| 状态 | 等式约束 | 不等式约束 | 说明 |
|------|----------|-----------|------|
| 正常运行状态 | 满足 | 满足 | 系统正常运行 |
| 不正常运行状态 | 满足 | 部分不满足 | 非故障但异常，如过负荷、频率降低、电压升高、振荡等 |
| 故障状态 | — | — | 短路、断线等，最常见最危险的是短路 |

### 1.1.2 故障（短路）的危害

1. 短路电流和电弧使故障元件损坏
2. 短路电流通过非故障元件，因发热和电动力引起损坏或缩短寿命
3. 部分地区电压大大降低，破坏用户正常工作
4. 破坏各发电厂并列运行稳定性，引起系统振荡甚至瓦解

**短路类型统计**：高压电网中单相短路接地次数占所有短路次数的**85%以上**。

### 1.1.3 事故与故障的区别

- **故障**：一次设备因外力、绝缘老化、过电压、误操作等原因导致短路、断线
- **事故**：系统或其一部分正常工作遭到破坏，造成少送电、电能质量恶化，甚至人身伤亡和设备损坏

### 1.1.4 电力系统控制操作的分类

| 类别 | 功能 | 特点 |
|------|------|------|
| **电力系统自动化（控制）** | 保证正常运行的经济性和电能质量 | 动作速度相对迟缓，连续调节 |
| **继电保护装置** | 反应故障或不正常运行状态，动作于跳闸或发信号 | 动作速度快，非连续调节 |
| **电网安全自动装置** | 故障后迅速恢复运行（重合闸、备自投、低电压切负荷等） | 防止大面积停电 |

### 1.1.5 继电保护的基本任务

1. **自动、迅速、有选择性**地将故障元件从电力系统中切除，保证无故障部分迅速恢复正常运行
2. 反应不正常运行状态，根据维护条件动作于发信号或跳闸（**不要求迅速动作**，规定一定延时以避免误动）

**继电保护系统**包括：保护原理、配置、整定、调试技术，以及从电流/电压互感器二次回路到断路器跳闸线圈的一整套设备。

## 1.2 继电保护的基本原理及组成

### 1.2.1 基本原理

**核心思想**：提取和利用电力元件在三种运行状态下的**"差异"**来区分运行状态。

可区分不同运行状态的电气量：
- 相电流、**序电流**、功率及其方向
- 运行相电压幅值、**序电压幅值**
- 电压与电流的比值（**测量阻抗** $Z_m = U_m / I_m$）

**纵联保护**：比较被保护元件两侧电气量差异的保护
- 电流差动保护：利用内部/外部短路时两侧电流矢量和之差
- 电流相位差动保护：利用两侧电流相位差别
- 方向比较式纵联保护：利用两侧功率方向差别

**其他保护类型**：气体保护（变压器）、过热保护（电动机）

### 1.2.2 保护装置的构成

继电保护装置由三部分组成：

| 组成部分 | 功能 |
|----------|------|
| **测量比较部分** | 测量物理参量，与整定值比较，给出逻辑信号（"0"或"1"） |
| **逻辑判断部分** | 根据逻辑信号的性质、顺序、持续时间，按逻辑关系判定故障类型和范围 |
| **执行输出部分** | 根据逻辑指令，发出跳闸脉冲、警报或不动作 |

### 1.2.3 工作回路

1. 电流/电压互感器及其与保护装置的连接电缆 → **合并单元**（智能变电站）
2. 断路器跳闸线圈及保护装置出口连接电缆 → **智能终端**（智能变电站）
3. 保护装置及跳闸、信号回路的工作电源

**智能变电站结构**："三层两网"——站控层、间隔层、过程层

## 1.3 对继电保护的基本要求（四性）

> **考点重点**：四性是分析研究继电保护的基础，必须反复深刻领会。

### 1.3.1 选择性

保护装置动作时，在**可能最小的区间内**将故障从电力系统中断开，最大限度保证无故障部分继续安全运行。

**保护配置**：

| 保护类型 | 说明 |
|----------|------|
| **主保护** | 快速切除任何类型的故障，最大限度缩小故障影响 |
| **远后备保护** | 下级元件的后备保护安装在上级断路器处，切除范围覆盖所有下级元件 |
| **近后备保护** | 与主保护安装在同一断路器处，主保护拒动时跳闸 |
| **断路器失灵保护** | 断路器失灵时，跳开所有与故障元件相连的电源侧断路器 |

> 主保护与后备保护之间存在**动作时间**和**动作灵敏度**的配合。

### 1.3.2 速动性

尽可能快地切除故障，减少设备及用户在大短路电流、低电压下运行的时间。

**故障切除时间 = 保护装置动作时间 + 断路器动作时间**

- 快速保护动作时间：0.06~0.12s，最快0.01~0.04s
- 断路器动作时间：0.06~0.15s，最快0.02~0.06s

**必须快速切除的故障**：
1. 使母线电压低于允许值（0.7倍额定电压）
2. 大容量发电机/变压器/电动机内部故障
3. 导线截面过小的线路故障（避免过热）
4. 可能危及人身安全、对通信/铁路信号有强干扰的故障

在高压电网中，维持**暂态稳定性**往往是速动性要求的决定性因素。

### 1.3.3 灵敏性（灵敏度）

保护装置对其保护范围内故障或不正常运行状态的**反应能力**。

- 灵敏系数 $K_{sen}$ 越大越好
- 校验条件：最不利的运行方式、故障类型下的最不灵敏情况
- **故障位置、故障类型、过渡电阻**均不能影响正确动作

### 1.3.4 可靠性

- **不拒动**（可信赖性）：保护范围内发生应反应的故障时可靠动作
- **不误动**（安全性）：不属于保护动作的任何情况下不动作

可靠性取决于：设计制造质量、接线复杂度、触点数量、配置选用、安装调试、运行维护。

> **矛盾关系**：提高不拒动的可靠性 ↔ 提高不误动的可靠性 往往矛盾。
> - 联系紧密的系统 → 强调**不拒动**
> - 联系薄弱、备用容量少的系统 → 强调**不误动**

### 1.3.5 四性之间的辩证关系

四项基本要求之间往往有矛盾：
- 既有选择性又速动的保护 → 结构复杂 → 可靠性降低
- 提高灵敏性 → 增加误动可能性 → 可靠性降低

**必须从被保护对象的实际情况出发，明确矛盾主次，取得矛盾的统一。**

# 第2章 电网的电流保护

## 2.1 单侧电源网络相间短路的电流保护

### 2.1.1 继电器

**继电器**：能自动执行断续控制的部件，输入量达到一定值时使输出发生预计的状态变化。

**继电特性**：无论起动和返回，动作都是明确干脆的，不可能停留在中间位置。

**返回系数**：
$$K_{re} = \frac{I_{re}}{I_{op}}$$

- 过电流继电器（过量动作继电器）的返回系数**恒小于1**
- 实际应用中要求 $K_{re} = 0.85 \sim 0.90$

### 2.1.2 短路电流的特征

**短路电流组成**：工频周期分量（主要）+ 暂态高频分量 + 衰减直流分量

**工频周期分量近似计算**：
$$I_d = \frac{K_{\Phi} \cdot E_{\Phi}}{Z_s + Z_d}$$

- $E_{\Phi}$：系统等效电源相电势
- $Z_d$：短路点至保护安装处阻抗
- $Z_s$：保护安装处到等效电源阻抗
- $K_{\Phi}$：短路类型系数（三相短路=1，两相短路=$\sqrt{3}/2$）

**运行方式**：
- **最大运行方式**：$Z_s$ 最小 → 短路电流最大
- **最小运行方式**：$Z_s$ 最大 → 短路电流最小

**短路电流随距离变化**：越靠近电源短路电流越大，越远离越小。关键是**在本线路末端和下条线路出口短路时电流没有差别**（因为距离几乎相同）。

---

### 2.1.3 电流速断保护（电流I段）

**定义**：反应于短路电流幅值增大而**瞬时动作**的电流保护。

#### 整定原则

**躲开下一条线路出口处短路**，即按最大运行方式下本线路末端三相短路电流整定：

$$I_{set}^{I} = K_{rel}^{I} \cdot I_{k\cdot max}$$

- $K_{rel}^{I} = 1.2 \sim 1.3$（可靠系数）
- $I_{k\cdot max}$：最大运行方式下被保护线路末端三相短路电流

**二次动作电流**（继电器侧）：
$$I_{op}^{I} = \frac{I_{set}^{I}}{n_{TA}} \cdot K_{con}$$

- $n_{TA}$：电流互感器变比
- $K_{con}$：接线系数（三相星形/两相星形=1，三角形接线=$\sqrt{3}$）

**动作时间**：取决于继电器固有动作时间（<10ms），考虑躲过避雷器放电时间（40~60ms），一般加装出口中间继电器，动作时间60~80ms。

#### 保护范围校验

在系统**最小运行方式下两相短路**时校验最小保护范围，要求**大于被保护线路全长的15%~20%**。

$$I_{set}^{I} = \frac{\frac{\sqrt{3}}{2} E_{\Phi}}{Z_{s\cdot max} + z_1 L_{min}}$$

#### 优缺点

| 优点 | 缺点 |
|------|------|
| 简单可靠，动作迅速 | 不能保护线路全长 |
| | 保护范围受系统运行方式变化影响大 |
| | 线路很短时可能没有保护范围 |

**特殊应用**：线路-变压器组接线时，速断保护可按躲开变压器低压侧短路整定，可保护线路全长。

---

### 2.1.4 限时电流速断保护（电流II段）

**定义**：带时限动作的电流保护，切除速断保护范围以外的故障，作为速断保护的后备。

**两个要求**：
1. 在任何情况下能保护**本线路全长**，且具有足够灵敏性
2. 力求具有**最小的动作时限**
3. 下条线路短路时保证下级保护优先切除故障（选择性）

#### 整定计算

**(1) 动作电流**：与下一条线路的电流I段配合

$$I_{set\cdot 2}^{II} = K_{rel}^{II} \cdot I_{set\cdot 1}^{I}$$

- $K_{rel}^{II} = 1.1 \sim 1.2$（可靠配合系数）

**引入目的**：防止保护2的II段范围超过保护1的I段范围。

**(2) 动作时限**：
$$t_2^{II} = t_1^{I} + \Delta t$$

- 时间级差 $\Delta t = 0.3 \sim 0.6s$，通常取 **0.5s**

**(3) 灵敏性校验**：
$$K_{sen} = \frac{I_{k\cdot B\cdot min}}{I_{set\cdot 2}^{II}} \geq 1.3 \sim 1.5$$

- $I_{k\cdot B\cdot min}$：最小运行方式下本线路末端两相短路电流

> 若灵敏系数不满足要求，需与下一条线路的**II段**配合，动作时限再增加一个$\Delta t$（一般为1~1.2s）。

#### 评价

| 优点 | 缺点 |
|------|------|
| 灵敏性较好，能保护线路全长 | 速动性差（0.5s延时） |
| 与I段联合工作可构成主保护 | 仅能做近后备，不能起远后备作用 |

---

### 2.1.5 定时限过电流保护（电流III段）

**定义**：起动电流按躲开**最大负荷电流**整定，动作时限为固定整定时间。

#### 起动电流计算原则

保护装置必须在外部故障切除后、电压恢复、电动机自起动时**可靠返回**：

$$I_{set}^{III} = \frac{K_{rel}^{III} \cdot K_{SS}}{K_{re}} \cdot I_{l\cdot max}$$

- $K_{rel}^{III} = 1.15 \sim 1.25$
- $K_{SS}$：自起动系数（>1，取决于负荷性质）
- $K_{re}$：返回系数（0.85~0.95）
- $I_{l\cdot max}$：最大负荷电流

#### 动作时限配合（阶梯原则）

从最末端的保护开始，向电源侧逐级增加一个$\Delta t$：
$$t_n^{III} = t_{n-1}^{III} + \Delta t$$

**阶梯原则**：越靠近电源端，动作时限越长。

#### 灵敏性校验

| 校验场景 | 要求 |
|----------|------|
| 作为本线路主保护时（近后备） | $K_{sen} \geq 1.3 \sim 1.5$ |
| 作为相邻线路后备保护时（远后备） | $K_{sen} \geq 1.2$ |

各保护的灵敏系数还需满足：$K_{sen.1} > K_{sen.2} > K_{sen.3} > K_{sen.4} > ...$（越靠近故障点灵敏系数越高）

---

### 2.1.6 阶段式电流保护的配合

三段式电流保护的配合关系：

| 段 | 名称 | 动作时间 | 保护范围 | 作用 |
|----|------|---------|---------|------|
| I段 | 电流速断 | 瞬时（60~80ms） | 线路首端一部分（≥15%~20%） | 主保护 |
| II段 | 限时电流速断 | 0.5s | 线路全长+延伸至下级 | 主保护+近后备 |
| III段 | 定时限过电流 | 阶梯时限 | 本线路全长+相邻线路全长 | 后备保护 |

**优点**：简单可靠，在35kV及以下电网广泛应用
**缺点**：受电网接线和运行方式变化影响大

---

### 2.1.7 反时限特性的电流保护

**定义**：动作时间与流过继电器中电流大小相关，电流大时动作时限短，电流小时动作时限长。

**反时限特性公式**：
$$t = \frac{0.14K}{\left(\frac{I}{I_{op}}\right)^{0.02} - 1}$$

- $K$：时间整定系数
- $I_{op}$：起动电流

**优点**：靠近电源的故障具有较小的切除时间
**缺点**：整定配合复杂，最小运行方式下动作时限可能较长
**应用**：主要用于单侧电源供电的终端线路和较小容量电动机

---

### 2.1.8 电流保护的接线方式

#### 三相星形接线
- 每相均装设电流继电器和互感器
- 可反应各种相间短路和接地短路
- 三个继电器输出并联（"或"回路）
- 中线上流回 $I_a + I_b + I_c$，正常约为0，接地时为$3I_0$
- 用于发电机、变压器等大型设备，可靠性灵敏性高

#### 两相星形接线（A、C相）
- 简单经济
- 中性点非直接接地电网中，两点接地时有2/3机会只切除一条线路
- 在中性点非直接接地电网中广泛应用
- **要求**：所有线路上保护装置均安装在相同两相上（一般A、C相）

#### Y,d变压器两侧故障电流分析（重要考点）

**三角形侧AB两相短路** → 星形侧：$I_A^Y = I_C^Y$，$I_B^Y = -2I_A^Y$

**星形侧BC两相短路** → 三角形侧：$I_A^\Delta = I_C^\Delta$，$I_B^\Delta = -2I_A^\Delta$

> 当过电流保护接于降压变压器高压侧作低压侧后备保护时，两相星形接线灵敏度比三相星形低一半。

### 2.1.9 阶段式电流保护例题（作业1）

## 2.2 双侧电源网络相间短路的方向性电流保护

### 2.2.1 问题的提出

双侧电源电网中，传统电流保护出现矛盾：
- K1点故障应保护4动作 → 要求 $I_{op.4} < I_{op.2}$
- K2点故障应保护2动作 → 要求 $I_{op.4} > I_{op.2}$

**本质**：误动作的保护都是在反方向故障时由对侧电源供给的短路电流引起的，此时功率方向为**线路流向母线**，与应保护的方向相反。

### 2.2.2 短路功率方向

**短路功率正方向**：规定功率方向由**母线流向线路**为正。

**特征**：短路功率的流动方向正是保护应该动作的方向。

### 2.2.3 功率方向判别元件

**定义**：用以判别功率或测定电流/电压之间相位角来判别故障方向的元件。

**基本要求**：
1. 正方向各种故障可靠动作，反方向故障可靠不动作
2. 故障时可靠动作且有足够灵敏度

#### 90°接线方式

采用非故障相间电压作为参考电压，消除电压死区：

| 相别 | 输入电流 | 输入电压 |
|------|----------|----------|
| A相 | $I_A$ | $U_{BC}$ |
| B相 | $I_B$ | $U_{CA}$ |
| C相 | $I_C$ | $U_{AB}$ |

#### 动作方程

$$U_r I_r \cos(\varphi_r + \alpha) > 0$$

或：$$90^\circ - \alpha \geq \arg\frac{U_r}{I_r} \geq -90^\circ - \alpha$$

- $\alpha$ 为功率方向继电器的**内角**
- 最大灵敏角 $\varphi_{sen} = -\alpha$
- 90°接线时，$\alpha = 90^\circ - \varphi_d$
- 内角范围：**$30^\circ < \alpha < 60^\circ$** 可保证各种故障情况下均正确动作

#### 电压死区问题

当采用 $U_A$、$I_A$ 接线时，正向出口三相短路时 $U_A \approx 0$，出现死区。

**消除方法**：采用非故障相间电压（90°接线方式）+ 电压记忆回路。

#### 潜动问题

**潜动**：只加入电流或只加入电压时继电器就能动作的现象。
所有功率方向元件必须可靠防止潜动。

---

### 2.2.4 方向性电流保护的整定配合

#### 分支电路的影响（分支系数）

$$K_b = \frac{\text{故障线路流过的短路电流}}{\text{前一级保护所在线路上流过的短路电流}}$$

**助增电流**：分支电源使故障线路电流增大（$K_b > 1$）
**外汲电流**：并联线路使故障线路电流减小（$K_b < 1$）

限时电流速断起动电流整定：
$$I_{set\cdot 2}^{II} = \frac{K_{rel}^{II}}{K_{b\cdot min}} \cdot I_{set\cdot 1}^{I}$$

> 取**最小分支系数**确保选择性。

#### 方向元件的加装原则

- 能用电流整定值保证选择性的，尽量不加方向元件
- 过电流保护：一条母线上除动作时限最长的一个外，其余均需装方向元件

## 2.3 中性点直接接地系统中接地短路的零序电流及方向保护

### 2.3.1 零序分量的特点

**零序电压**：
- 零序电源在**故障点**，故障点零序电压最高
- 距故障点越远处零序电压越低
- 正方向：线路高于大地为正

**零序电流**：
- 分布主要决定于零序阻抗和中性点接地变压器零序阻抗
- **与电源数目和位置无关**
- 正方向：由母线流向线路为正
- 流过保护1的零序电流超前 $U_{d0}$ 约 $90^\circ \sim 100^\circ$

**零序功率方向**：
- 故障线路两端零序功率方向与正序功率方向**相反**
- 零序功率由**线路流向母线**

### 2.3.2 零序电压/电流滤过器

**零序电压获取**：
- 三相五柱式电压互感器，二次绕组接成开口三角形
- 发电机中性点经电压互感器接地
- 数字保护中由加法器将三个相电压相加

**零序电流获取**：
- 三相电流互感器并联连接（零序电流过滤器）
- 零序电流互感器（无不平衡电流，接线更简单）

### 2.3.3 零序电流保护的分段

| 段 | 整定原则 | 保护范围 | 灵敏系数要求 |
|----|----------|---------|------------|
| **I段** | 躲开下级出口最大零序电流 $I_{set}^{I} = K_{rel}^{I} \cdot 3I_{0\cdot max}$ | 线路首端一部分（>15%） | — |
| **II段** | 与下级I段配合 $I_{set\cdot 2}^{II} = \frac{K_{rel}^{II}}{K_{0\cdot b}} \cdot I_{set\cdot 1}^{I}$ | 本线路全长 | $K_{sen} \geq 1.5$ |
| **III段** | 逐级配合，躲开最大不平衡电流 | 本线路全长+相邻线路 | 近后备≥1.3~1.5，远后备≥1.2 |

**灵敏I段与不灵敏I段**：
- 灵敏I段：按躲开下级出口最大零序电流整定，用于全相运行状态
- 不灵敏I段：按躲开非全相振荡时的零序电流整定，用于单相重合闸过程中

### 2.3.4 零序功率方向元件

- 零序电压 $3U_0$ 和零序电流 $3I_0$
- 正方向故障时，$3I_0$ 超前 $3U_0$ 约 $85^\circ \sim 110^\circ$（零序阻抗角）
- 最灵敏角取为 $-95^\circ \sim -110^\circ$
- **零序功率方向元件无死区**（与相间功率方向元件不同）

### 2.3.5 零序电流保护的评价

| 优点 |
|------|
| 灵敏度高，动作时限比相间保护短 |
| 受系统运行方式变化影响小得多，保护范围较稳定 |
| 系统振荡、短时过负荷时不受影响（三相对称） |
| 零序功率方向元件无死区 |
| 简单、经济、可靠 |

## 2.4 中性点非直接接地系统中单相接地故障的保护

### 2.4.1 中性点不接地电网单相接地故障的特点

**故障特征**：
- 故障相电压降为0，非故障相电压升高为线电压（$\sqrt{3}$倍）
- 但线电压仍对称，可继续运行1~2小时
- 接地电流为全系统非故障相电容电流之和：$I_D = 3U_\Phi \omega C_\Sigma$

**接地电流估算**：
- 架空线路：$I_d = UL/350$
- 电缆线路：$I_d = UL/10$
（$U$ 为线电压kV，$L$ 为线路总长km）

**适用范围**（接地电流不超过以下值）：
- 3~10kV系统：$I_d \leq 30A$
- 20~60kV系统：$I_d \leq 10A$
- 与发电机直连的3~20kV系统：$I_d \leq 5A$

**零序分量分布特点**：
1. 零序网络由对地等值电容构成通路，零序阻抗很大
2. 非故障元件零序电流 = 本身对地电容电流，方向：**母线→线路**
3. 故障元件零序电流 = 全系统非故障元件电容电流总和，方向：**线路→母线**

### 2.4.2 中性点经消弧线圈接地

**目的**：减小接地电流，使电弧不能持续，避免过电压威胁绝缘。

**消弧线圈**：在中性点接入电感线圈，电感电流与电容电流在接地点抵消。

**补偿方式**：

| 方式 | 特点 |
|------|------|
| 完全补偿 | $I_L = I_{C\Sigma}$，但可能引起串联谐振过电压，**不采用** |
| 欠补偿 | $I_L < I_{C\Sigma}$，不常用 |
| **过补偿** | $I_L > I_{C\Sigma}$，补偿度 $P = 5\% \sim 10\%$，**被广泛采用** |

> 过补偿时，故障线路零序电流方向与非故障线路方向相同（均为母线→线路），因此**无法用零序功率方向判别故障线路**。

### 2.4.3 零序电压保护

利用母线零序电压的监视装置，带延时动作于信号。**无选择性**，需由运行人员依次断开线路来查找故障线路。

### 2.4.4 零序电流保护和零序功率方向保护

- 利用故障线路零序电流大于非故障线路的特点
- 起动电流：$I_{set} = K_{rel} \cdot 3U_\Phi \omega C_0$（大于本线路电容电流）
- 灵敏系数：$K_{sen} = \frac{C_\Sigma - C_0}{K_{rel} \cdot C_0}$

# 第3章 电网距离保护

## 3.1 距离保护的基本原理与构成

### 3.1.1 距离保护的概念

**距离保护**：利用短路时电压、电流同时变化的特征，测量电压与电流的比值（**测量阻抗**），反应故障点到保护安装处的**距离**而工作的保护。

$$Z_m = \frac{U_m}{I_m} = z_1 \cdot L_k$$

### 3.1.2 测量阻抗

**测量阻抗**：保护安装处测量电压与测量电流之比
$$Z_m = \frac{\dot{U}_m}{\dot{I}_m} = R_m + jX_m$$

- **负荷阻抗**：量值大，阻抗角为功率因数角（≤25.8°），以阻性为主
- **短路阻抗**：$Z_k = Z_1 \cdot L_k$，阻抗角等于线路阻抗角（≥75°），以感性为主

**判断逻辑**：
- $Z_m < Z_{set}$ → $L_k < L_{set}$ → 区内故障，动作
- $Z_m > Z_{set}$ → $L_k > L_{set}$ → 区外故障，不动作

**关键公式**：$U_m / I_m = z_1 \cdot L_k$

### 3.1.3 三相系统中测量电压和测量电流的选取

**故障环路概念**：

| 故障类型 | 故障环路 |
|----------|----------|
| 单相接地 | 一个相-地故障环 |
| 两相接地 | 两个相-地环 + 一个相-相环 |
| 两相不接地 | 一个相-相环 |
| 三相短路接地 | 三个相-地环 + 三个相-相环 |

**接线方式汇总表**：

| 故障类型 | 测量电压 | 测量电流 |
|----------|---------|---------|
| 单相接地（A相） | $U_A$ | $I_A + K \cdot 3I_0$ |
| 两相接地/不接地 | $U_{AB}$（相间电压） | $I_A - I_B$（相间电流差） |
| 三相短路 | 任一相电压 | 对应相电流 |

**0°接线**：相电压与带零序电流补偿的相电流

> $K$ 为零序电流补偿系数

### 3.1.4 距离保护的时限特性

采用三段式阶梯时限特性：

| 段 | 延时 | 动作时间 |
|----|------|----------|
| **距离I段** | 无延时速动段 | 瞬时 |
| **距离II段** | 带固定时限 | 0.3~0.6s |
| **距离III段** | 与相邻下级III段配合+Δt | ≥1~1.5s |

### 3.1.5 距离保护的构成

- **启动部分**：远后备保护范围末端故障时灵敏快速启动（几毫秒）
- **测量部分**：快速准确测定故障方向和距离，与整定值比较

## 3.2 阻抗继电器及其动作特性

> **考点重点**：用复平面分析各种圆特性、直线特性阻抗继电器，掌握幅值比较和相位比较表达式。

### 3.2.1 动作区域

阻抗继电器将复平面分为动作区与非动作区，临界动作为动作边界。常用形状：
- 圆形（全阻抗、方向阻抗、偏移阻抗）
- 直线形（电抗特性、电阻特性、方向特性）
- 多边形（四边形、准四边形）
- 复合特性

### 3.2.2 圆特性阻抗继电器

#### （1）全阻抗继电器

**定义**：以安装点为圆心，整定阻抗$Z_{set}$为半径的圆（圆内动作）。

**特点**：动作值与阻抗角无关，**无方向性**。

**幅值比较式**：$Z_m \leq Z_{set}$ 或 $U_m \leq Z_{set} \cdot I_m$

**相位比较式**：
$$-90^\circ \leq \arg\frac{Z_{set} - Z_m}{Z_{set} + Z_m} \leq 90^\circ$$

#### （2）方向阻抗继电器

**定义**：以整定阻抗$Z_{set}$为直径且通过坐标原点的圆（圆内动作）。

**特点**：
1. 起动阻抗与阻抗角有关，$\varphi_m = \varphi_{set}$时起动阻抗最大
2. **具有方向性**，反向故障不动作
3. **有死区**（出口短路时$Z_m \approx 0$，处于临界边界）

**幅值比较式**：
$$\left|Z_m - \frac{1}{2}Z_{set}\right| \leq \left|\frac{1}{2}Z_{set}\right|$$

**相位比较式**：
$$-90^\circ \leq \arg\frac{Z_{set} - Z_m}{Z_m} \leq 90^\circ$$

#### （3）偏移阻抗继电器

**定义**：以 $Z_{set}$ 和 $-\alpha Z_{set}$ 末端连线为直径的圆（$\alpha$ 为偏移率，通常0.1~0.2）。

**特点**：
1. 在一定范围内具有方向性
2. **消除了保护安装处的死区**
3. 常用于距离保护的**后备段（III段）**

**幅值比较式**（通用形式）：
$$\left|Z_m - \frac{1}{2}(Z_{set1} + Z_{set2})\right| \leq \left|\frac{1}{2}(Z_{set1} - Z_{set2})\right|$$

**相位比较式**（通用形式）：
$$-90^\circ \leq \arg\frac{Z_{set1} - Z_m}{Z_m - Z_{set2}} \leq 90^\circ$$

#### 各圆特性总结

| 特性 | $Z_{set1}$ | $Z_{set2}$ | 特点 |
|------|-----------|-----------|------|
| 方向圆 | $Z_{set}$ | 0 | 有方向性，有死区 |
| 全阻抗圆 | $Z_{set}$ | $-Z_{set}$ | 无方向性，无死区 |
| 偏移圆 | $Z_{set}$ | $-\alpha Z_{set}$ | 有方向性，无死区 |
| 上抛圆 | $Z_A$ | $Z_B$（均在第一象限） | 用于发电机失磁保护 |

### 3.2.3 苹果形和橄榄形特性

以方向圆特性为例，当相位比较动作范围不等于180°时：

- **苹果形**：$\beta > 90^\circ$，耐受过负荷能力较强，耐过渡电阻能力较弱
- **橄榄形**：$\beta < 90^\circ$，耐过渡电阻能力较强，耐受过负荷能力较弱

### 3.2.4 直线特性的阻抗元件

| 特性 | 动作区域 | 特点 | 动作方程 |
|------|---------|------|---------|
| **电抗特性** | 平行于R轴直线下方 | 耐过渡电阻能力强，无方向性 | $X_m \leq X_{set}$ |
| **电阻特性** | 平行于jX轴直线左侧 | 无方向性 | $R_m \leq R_{set}$ |
| **方向特性** | 经过原点，与$Z_{set}$垂直直线的右侧 | 具有方向判别能力 | — |

> 直线特性通常不能独立应用，需与其他特性复合。

### 3.2.5 多边形特性（四边形特性）

**特点**：同时兼顾耐受过渡电阻能力和躲负荷能力。

**四边形特性**由三个直线方程相"与"构成：
1. 准电抗特性直线
2. 准电阻特性直线
3. 折线特性（相位比较原理）

**准四边形特性动作方程**（数字化实现）：
$$\begin{cases} -\frac{1}{4}\hat{X}_m \leq R_m \leq R_{set} + \hat{X}_m \\ -\frac{1}{4}\hat{R}_m \leq X_m \leq X_{set} - \frac{1}{8}R_m \end{cases}$$

### 3.2.6 绝对值比较与相位比较的相互转换

基本转换关系（平行四边形对角线）：
$$Z_C = Z_B + Z_A, \quad Z_D = Z_B - Z_A$$
$$Z_B = \frac{1}{2}(Z_C + Z_D), \quad Z_A = \frac{1}{2}(Z_C - Z_D)$$

> 已知绝对值比较方程 $|Z_A| \leq |Z_B|$，可导出相位比较方程 $-90^\circ \leq \arg\frac{Z_C}{Z_D} \leq 90^\circ$，反之亦然。

## 3.3 阻抗继电器的实现方法

### 3.3.1 绝对值比较原理的实现

**电压形式**：$|\dot{U}_B| \leq |\dot{U}_A|$

- 模拟式：通过电压变换器（TV）和电抗变换器（TX）形成电压
- 数字式：电压比较算法（直接比较）或阻抗比较算法（先算$Z_m$再判断）

**电抗变换器**的作用：
- 将TA二次电流变换成成正比且超前一定角度的电压
- 隔离保护回路与CT二次回路
- 可滤除直流分量

### 3.3.2 相位比较原理的实现

**余弦型相位比较判据**（动作范围-90°~90°）：
$$U_{CR}U_{DR} + U_{CI}U_{DI} \geq 0$$

**正弦型相位比较判据**（动作范围0°~180°）：
$$U_{CI}U_{DR} - U_{CR}U_{DI} \geq 0$$

**瞬时采样值比相（两点积算法）**：
- 余弦型：$u_C(n-\frac{N}{4}) \cdot u_D(n-\frac{N}{4}) + u_C(n) \cdot u_D(n) \geq 0$
- 正弦型：$u_C(n-\frac{N}{4}) \cdot u_D(n) - u_C(n) \cdot u_D(n-\frac{N}{4}) \geq 0$
- 仅需相隔1/4周期的两个采样值

### 3.3.3 比较工作电压相位法

**工作电压（补偿电压）**：
$$\dot{U}_{op} = \dot{U}_m - \dot{I}_m \cdot Z_{set}$$

**基本原理**：
- 正方向区内故障（$k_1$点）：$\dot{U}_{op}$ 与 $\dot{U}_m$ **反相位**
- 正方向区外故障（$k_2$点）：$\dot{U}_{op}$ 与 $\dot{U}_m$ **同相位**
- 反方向区外故障（$k_3$点）：$\dot{U}_{op}$ 与 $\dot{U}_m$ **同相位**

**动作条件**（考虑误差）：
$$\beta_1 \leq \arg\frac{\dot{U}_{op}}{\dot{U}_{ref}} \leq \beta_2$$

#### 以正序电压为参考电压

**优点**：
- 正向出口短路时特性变为包含原点的偏移圆，可靠动作
- 耐受过渡电阻能力比方向阻抗强

**出口不对称短路时**：
- 单相接地：故障相正序电压 = 故障前电压 × 2/3
- 两相接地：故障相正序电压 = 故障前电压 × 1/3
- 两相不接地：故障相正序电压 = 故障前电压 × 1/2
- 三相短路：正序电压=0（无法应用）

#### 以记忆电压为参考电压

记忆电压 = 故障前电压（存储在存储器中）

**模拟式**：通过LC谐振记忆回路获得，逐渐衰减
**数字式**：存储在存储器中的故障前电压采样值，不衰减但仅限故障后一定时间使用

> 结论：工作电压相同的情况下，选取不同参考电压可获得不同动作特性。

### 3.3.4 精确工作电流与精确工作电压

**精确工作电流**：使继电器实际动作阻抗等于整定阻抗90%时的测量电流。

- 最小精确工作电流：校验条件是保护区内短路时测量电流 ≥ 最小精工电流 × 裕度系数（1.5~2）
- 最大精确工作电流：一般不必校验

**精确工作电压**：较短线路末端短路时测量电压可能较低，需校验最小精工电压。

> 仅当实际测量电流在最小和最大精工电流之间、测量电压在最小精工电压以上时，三段式距离保护才能准确配合工作。

## 3.4 距离保护的整定计算

### 3.4.1 距离保护第I段的整定

**原则**：按躲过本线路末端短路时的测量阻抗整定。

$$Z_{set}^{I} = K_{rel}^{I} \cdot Z_{AB}$$

- $K_{rel}^{I} = 0.8 \sim 0.85$（距离保护为欠量动作，可靠系数 < 1）
- $Z_{AB}$：被保护线路全长的正序阻抗
- 动作时间：**无延时（瞬时）**

### 3.4.2 距离保护第II段的整定

**原则一**：与相邻线路距离I段配合
$$Z_{set\cdot 1}^{II} = K_{rel}^{II} \cdot (Z_{AB} + K_{b\cdot min} \cdot Z_{set\cdot 2}^{I})$$

- $K_{rel}^{II} = 0.8$
- $K_{b\cdot min}$：最小分支系数

**原则二**：与相邻变压器快速保护配合
$$Z_{set\cdot 1}^{II} = K_{rel}' \cdot Z_{12} + K_{rel}'' \cdot K_b \cdot Z_t$$

- 可靠系数一般取 $0.7 \sim 0.75$（变压器阻抗误差较大）

> 取两种计算结果中的**较小者**作为整定阻抗。

**灵敏性校验**：
$$K_{sen} = \frac{Z_{set}^{II}}{Z_{AB}} \geq 1.25$$

**动作时间**：$t_1^{II} = t_2^{(x)} + \Delta t$（比相邻保护大一个级差）

### 3.4.3 距离保护第III段的整定

**原则**：与相邻下级线路距离保护II段或III段配合，取较小者。

- III段通常采用**偏移特性**，偏移率一般取5%左右
- 动作时间比相邻保护最大动作时间大$\Delta t$，一般为 **1.5~2s**（足够躲过振荡周期）
- 灵敏系数：
  - 本线路末端短路：$K_{sen(1)} \geq 1.5$
  - 相邻线路末端短路：$K_{sen(2)} \geq 1.2$

### 3.4.4 整定值的二次侧换算

$$Z_{m(2)} = \frac{n_{TA}}{n_{TV}} \cdot Z_{m(1)}$$
$$Z_{set(2)} = \frac{n_{TA}}{n_{TV}} \cdot Z_{set(1)}$$

## 3.5 距离保护的振荡闭锁

> **考点重点**：振荡对距离保护的影响及闭锁措施

### 3.5.1 振荡的基本概念

**电力系统振荡**：并联运行系统间出现功率角大范围周期性变化的现象。属于**严重不正常运行状态**，不是故障。

**振荡闭锁**：防止系统振荡时保护误动的措施。

### 3.5.2 振荡对测量元件的影响

#### 电流电压变化规律

假设 $|E_M| = |E_N|$，功角为 $\delta$：

电流有效值：$I = \frac{2E_M}{Z_\Sigma} \sin\frac{\delta}{2}$

**振荡中心**：电压最低的点，位于阻抗中心 $\frac{1}{2}Z_\Sigma$ 处。

振荡中心电压：$U_{os} = E_M \cos\frac{\delta}{2}$

当 $\delta = 180^\circ$ 时，振荡中心电压为0。

#### 测量阻抗变化

$$Z_m = \frac{Z_\Sigma}{1 - e^{-j\delta}} - Z_M = \left(\frac{1}{2} - \rho_M\right)Z_\Sigma - j\frac{1}{2}Z_\Sigma \cot\frac{\delta}{2}$$

- $\rho_M = Z_M/Z_\Sigma$：M侧系统阻抗占比
- 测量阻抗末端轨迹是一条垂直于$Z_\Sigma$的直线（$oo'$线）

**三种情况**：
- $\rho_M < 1/2$（振荡中心在正方向）→ 测量阻抗穿越动作区
- $\rho_M = 1/2$（安装处即振荡中心）→ **肯定穿越动作区**
- $\rho_M > 1/2$（振荡中心在反方向）→ 视特性而定

#### 影响因素

- 距振荡中心越近、整定值越大、动作区垂直于$Z_{set}$方向越宽 → 越容易误动
- 振荡周期越长 → 误动时间越长

### 3.5.3 振荡与短路的电气量差异

| 差异项 | 短路 | 振荡 |
|--------|------|------|
| 电气量变化 | 突变 | 缓慢变化 |
| 三相对称性 | 不对称短路时有负序/零序 | 三相对称，无负序/零序 |
| 阻抗变化率 | 大 | 小 |

### 3.5.4 振荡闭锁措施

#### （1）利用负序/零序分量或电流突变量实现短时开放

**故障判断元件**（启动元件）：
- **负序/零序分量判断**：振荡时三相对称，无负序/零序；短路时出现
- **电流突变量判断**：振荡时电流变化缓慢，短路时突变

**短时开放**：无故障时距离保护一直闭锁，故障时短时开放允许跳闸。

**整组复归**：故障或振荡消失后延时复归，保证整个故障过程中只开放一次。

#### （2）利用阻抗变化率不同（"大圆套小圆"原理）

短路时阻抗变化率大，$Z_1$、$Z_2$动作时间差 < Δt，短时开放；振荡时阻抗变化率小，时间差 > Δt，保持闭锁。

#### （3）利用动作延时实现振荡闭锁

按躲过最大负荷整定的III段阻抗继电器，振荡时测量阻抗落入动作区的时间一般不超过1~1.5s，只要III段延时 ≥ 1.5s就不会误动。

### 3.5.5 振荡过程中再故障的判断

**不对称短路**判据：
$$\frac{I_2 + I_0}{I_1} \geq m \quad (m = 0.5 \sim 0.7)$$

**三相对称故障**：通过检测阻抗变化率等方法判别。

## 3.7 距离保护特殊问题的分析

### 3.7.1 过渡电阻对距离保护的影响

**过渡电阻 $R_g$**：短路电流从一相流到另一相或流入大地时经过物质的电阻。

**电弧电阻估算**（相间故障）：
$$R_g = 1050 \cdot \frac{L_g}{I_g}$$

- $L_g$：电弧长度（m），$I_g$：电弧电流（A）

**影响规律**：
- 保护距短路点越近 → 受过渡电阻影响越大
- 整定阻抗越小（线路越短）→ 受过渡电阻影响越大
- 双侧电源时，对侧电源提供的助增电流使测量阻抗中$R_g$的影响被放大

**克服措施**：
- 采用能容许较大过渡电阻的动作特性：
  - 偏移特性 > 方向阻抗特性
  - 四边形特性 > 圆特性
  - 动作特性向+R轴偏转
- 四边形上边适当向下倾斜可防止稳态超越

### 3.7.2 串联补偿电容对距离保护的影响

**补偿度**：$K_{com} = X_C / X_l$

串补电容后短路阻抗与短路距离不再成正比关系，在电容前后发生突变。具体影响取决于安装位置和容抗大小。

### 3.7.3 非工频分量对距离保护的影响

电磁暂态过程中（几十到上百毫秒），电压电流含有大量非工频暂态分量（衰减直流分量、谐波、高频分量），影响保护测量精度。
